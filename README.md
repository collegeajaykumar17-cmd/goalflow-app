# GoalFlow Mobile App

A mobile-first productivity Progressive Web App (PWA) prototype.

## Features
- Dashboard with daily task completion progress
- Yearly, monthly, and weekly goals with deadlines
- Daily task list with priorities
- Flexible habit tracker with Mini / Plus / Elite levels
- Daily wellbeing check-in (sleep, water, mood, movement, reflection)
- Monthly review form
- Idea parking lot
- Export data as JSON
- Local storage, so data stays in this browser on this device
- PWA manifest and service worker for install/offline caching when hosted on HTTPS or localhost

## Run on your laptop
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Run a local server. One easy option: install the VS Code extension **Live Server**, right-click `index.html`, then choose **Open with Live Server**.
4. To test mobile view in Chrome, press `F12`, then click the device toolbar icon.
5. To install on Android, host the folder on an HTTPS website, open the website in Chrome on your phone, then choose **Install app** or **Add to Home screen**.

## Important
This is a working front-end prototype, not a Play Store APK. It stores data in the browser on the current device. It does not sync between devices or send push notifications. Avoid entering sensitive personal information.
